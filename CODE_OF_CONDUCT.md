# Code of Conduct

## Our pledge

SWARA XT is an open-source audio-software project maintained by MontroneDSP.
We pledge to make participation in this project welcoming, respectful, and free
from harassment.

## Expected behavior

Participants are expected to communicate constructively, respect differing
opinions and experiences, give and accept good-faith technical feedback, and
focus discussions on improving the project and its community.

## Unacceptable behavior

Unacceptable behavior includes harassment; threats; hateful, derogatory, or
personal attacks; sexualized language or imagery; deliberate disruption;
trolling; publishing another person's private information without permission;
and other conduct that a reasonable person would consider unprofessional or
unsafe.

## Scope

This Code applies to project spaces, including issues, pull requests,
discussions, reviews, and project-managed communication channels. It also
applies when someone represents SWARA XT or MontroneDSP in a public project
context.

## Reporting

Report a Code of Conduct concern privately to
[support@montronedsp.com](mailto:support@montronedsp.com). Please do not post
reports containing sensitive personal information in a public issue.

## Enforcement

MontroneDSP reviews reports fairly and as promptly as practical, with respect
for the reporter's privacy. Depending on the circumstances, responses may
include a private correction, a warning, temporary restriction from project
spaces, removal of content, or a permanent ban. When appropriate, the
maintainer will explain a moderation decision to the affected participant.

## Maintainer responsibility

The project maintainer is responsible for clarifying these standards and for
applying them consistently to project participation. Maintainers may remove,
edit, or reject contributions and communications that are not aligned with this
Code.
