- MontroneDSP-owned commits use the intended local Git identity (`montronedsp` / `montronedsp@users.noreply.github.com` in this repository).
- Do not insert automated co-author trailers.
- `Co-authored-by: Cursor <cursoragent@cursor.com>` is forbidden for agent-created commits.
- Inspect every outgoing commit message and identity before push.
- Preserve real human co-author attribution when it is already legitimate.
- Do not rewrite existing branches without explicit owner authorization.
- `main` remains protected. Opening or updating a PR is not authorization to merge.
- Source-bound CI evidence belongs to an exact commit SHA; rewriting commits invalidates prior exact-SHA results.
