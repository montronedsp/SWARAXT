Swara XT 1.2.3
MontroneDSP

Windows requirements
--------------------
64-bit Windows 10 or Windows 11.

VST3 installation
-----------------
Copy the complete "Swara XT.vst3" bundle from the VST3 folder to:

C:\Program Files\Common Files\VST3\

Do not copy only the DLL contained inside the bundle. If Windows asks for
administrator permission when writing to Program Files, approve it. Rescan
plugins in your DAW if Swara XT does not appear immediately.

Standalone
----------
Run "Swara XT.exe" directly from the Standalone folder, or copy the executable
to a location of your choice.

Skin Editor
-----------
Run "SWARA XT Skin Editor.exe" from the Skin Editor folder for a live colour
preview, then Install for Plugin or Save As a colour text file.

Skin Examples
-------------
The Skin Examples folder contains starter SVG/PNG/TXT assets
(manufacturer mark watermark, column decoration, background, and colours).
Load them from the Skin Editor or from the plugin editor context menus.
Installed user copies live under:

%APPDATA%\MontroneDSP\Swara XT\skin_assets\
