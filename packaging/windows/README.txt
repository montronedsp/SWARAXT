Swara XT 1.1.2
MontroneDSP

Windows requirements
--------------------
64-bit Windows 10 or Windows 11.

VST3 installation
-----------------
Copy the complete "Swara XT.vst3" bundle from the VST3 folder to:

C:\Program Files\Common Files\VST3\

Do not copy only the DLL contained inside the bundle. If Windows asks for
administrator permission when writing to Program Files, approve it. Rescan
plugins in your DAW if Swara XT does not appear immediately.

Standalone
----------
Run "Swara XT.exe" directly from the Standalone folder, or copy the executable
to a location of your choice.
