# Midnight Gold assets

These runtime SVGs are deterministic normalized exports from the Swara XT canonical design library. Regenerate them with `scripts/normalize-svg-assets.ps1`; do not hand-edit generated files.

- `midnight_product_lockup.svg` is the retained-vector composite built from the canonical instrument, wordmark, tagline, and svara geometry.
- MontroneDSP branding, frames, and ornaments are project design assets.
- `braid.svg` derives from the supplied Mutable/Shruthi visual asset and retains the upstream project provenance described in `docs/SOURCE_PROVENANCE.md` and `THIRD_PARTY_NOTICES.md`.
- The source master artwork remains outside this runtime directory and is not modified by the normalization script.
