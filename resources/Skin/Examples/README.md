# Custom skin SVG examples

Use these as starting points for user-loaded manufacturer marks and column decorations.

| File | Menu | Installed name |
|------|------|----------------|
| `manufacturer_mark_example.svg` | Manufacturer Mark → Load SVG… | `skin_assets/manufacturer_mark.svg` |
| `decoration_example.svg` | Decoration → Load SVG… | `skin_assets/decoration.svg` |

Preferences folder (same place as `Swara XT.settings`):

- Windows: `%APPDATA%\MontroneDSP\Swara XT\`
- Linux: `~/.config/MontroneDSP/Swara XT/`
- macOS: `~/Library/Application Support/MontroneDSP/Swara XT/`

Limits: `.svg` only, max 256 KiB, message-thread load only. Clear custom SVG from the same menus to restore the built-in art.
